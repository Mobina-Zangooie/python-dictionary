# Python Dictionary

A graphical English–Persian dictionary application built with Python and Tkinter.

## Overview

This graphical desktop application supports saving new vocabulary, looking up words, and retrieving translations online.

The application can also be packaged as a standalone Windows executable (.exe) with a custom icon.

## Features

- Graphical user interface built with Tkinter
- Local vocabulary storage using JSON
- Add and save new words
- Online translation using an external translation API
- Network and file error handling
- Windows executable packaging with a custom icon

## Technologies

- Python
- Tkinter
- JSON
- Requests
- PyInstaller

## Data Storage

The application stores vocabulary in a JSON file. Keep the data file alongside the application in the location expected by the program so that saved words remain accessible.

This project provided hands-on practice with:

- Input validation and exception handling
